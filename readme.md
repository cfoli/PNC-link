# PNC NEXUS

Transition planning prototype for business owners: landing page, sign in / sign up, Duolingo-style onboarding, and an owner analytics dashboard (valuation range, readiness radar, proceeds waterfall, scenario comparison).

Static site — no build step. Open `index.html` through any static server, e.g.

```sh
python3 -m http.server 8080
```

Accounts and answers are stored in the browser's localStorage only. All figures are illustrative demo data.
